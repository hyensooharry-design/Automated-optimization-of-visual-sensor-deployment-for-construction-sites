# Visual Sensor Location Optimization for Construction Site Modeling

This repository contains the final result artifacts selected from the `강진광주 파일` experiment set.

## Structure

- `FAST/`: rapid experiment result runs
- `PRECISION/`: precision experiment result runs

## Contents

Each run folder contains:

- `coverage.png`
- `results.xlsx`
- either `greedy_final.png` or multiple `frame_*.png` files
